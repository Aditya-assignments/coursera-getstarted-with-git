# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a Bash scripting project that calculates simple interest using the principal amount, rate of interest, and time period provided by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input Details
- **Principal:** The initial amount of money.
- **Rate of Interest:** The annual interest rate, expressed as a percentage.
- **Time Period:** The duration of the investment or loan in years.

## Output
The calculator displays the simple interest calculated from the given input values.

## Technology Used
- Bash Shell Scripting
- Linux Command Line

## Project Objective
The objective is to practice basic shell scripting, user input, arithmetic operations, and output formatting while developing a simple interest calculator.
